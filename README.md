# 🚗 UK Road Casualty Analysis 2025

## 📌 Overview
This project performs an end-to-end exploratory data analysis (EDA) on UK road accident data to uncover patterns in collision severity, timing, environmental conditions, and demographics.

---

## 🎯 Objectives
- Analyze accident severity (Fatal, Serious, Slight)
- Identify high-risk time periods
- Study environmental and road conditions
- Understand demographic impact
- Explore vehicle involvement patterns

---

## 📊 Key Insights
- 🚨 Peak accident time: **3 PM – 6 PM**
- 🚨 Most dangerous day: **Friday**
- 🚨 Urban collisions: **66.6%**
- 🚨 Most affected group: **Car occupants**
- 🚨 Majority accidents occur in **dry & daylight conditions**
